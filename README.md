📱 React Native Video Upload App
A mobile app built with React Native that allows users to select and upload videos from their device.

✨ Features
📹 Select videos from device gallery

⏫ Upload videos to a remote server or cloud storage (e.g. Firebase / Appwrite)

📤 Upload progress indicator

📁 Video metadata handling (name, duration, etc.)

🧪 Basic UI for testing video upload flow

🚀 Tech Stack
React Native (with or without Expo)

React Navigation

Firebase / Appwrite / or custom backend (for upload)

react-native-video / expo-av (optional for video preview)

📦 Installation
bash
Copy code
git clone https://github.com/sahildevstory/React-Native-VideoUpload-App.git
cd React-Native-VideoUpload-App
npm install
npx react-native run-android # or run-ios
🧪 Usage
Open the app

Tap to select a video

Preview and confirm

Upload to server
